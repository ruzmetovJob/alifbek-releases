# Alifbek

Приложение для преобразования узбекского текста между кириллицей, текущей латиницей и латиницей с ö, ğ, ş, ç.

## Скачать

Откройте [последний релиз](https://github.com/ruzmetovJob/alifbek-releases/releases/latest):

- **Alifbek-Setup** — установщик для Windows x64.
- **Alifbek-Portable** — запуск без установки.

Начиная с установленной версии 0.1.2 приложение проверяет новые релизы и предлагает обновление.

Alifbek вдохновлён проектом [alifbo](https://github.com/azakapro/alifbo), автор — Azizullo Temirov. Для преобразования используется оригинальная библиотека alifbo; её MIT-лицензия включена в приложение.
